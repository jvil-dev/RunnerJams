# Triage labels

The skills speak in terms of five triage roles. This file maps those roles to the label strings used in this repo's issue tracker.

| Role in mattpocock/skills | Label here        | Meaning                                  |
| ------------------------- | ----------------- | ---------------------------------------- |
| `needs-triage`            | `needs-triage`    | Needs to be evaluated                    |
| `needs-info`              | `needs-info`      | Waiting on more information              |
| `ready-for-agent`         | `ready-for-agent` | Fully specified, ready for an agent      |
| `ready-for-human`         | `ready-for-human` | Requires the developer to implement it   |
| `wontfix`                 | `wontfix`         | Will not be actioned                     |

When a skill mentions a role, use the label string from this table.
