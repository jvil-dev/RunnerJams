# Security policy

## Supported versions

RunnerJams has no tagged release yet. Fixes land on `main`.

## Reporting a vulnerability

Report it privately through this repository's **Security** tab, under **Report a
vulnerability**. Include a description, steps to reproduce, and the affected commit. Do not open
a public issue. Expect an acknowledgement within seven days.

## Practices

Dependabot alerts and security updates, and secret scanning with push protection, run on this
repository. CodeQL scans the GitHub Actions workflows. Environment files are never committed.
